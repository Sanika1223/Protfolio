# Sanika Parate — Portfolio Website

A responsive React + Vite portfolio with a blue cinematic theme, a custom ballerina illustration, and GSAP scroll choreography.

## Run locally

1. Install Node.js (LTS recommended).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173/).

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. You can deploy this Vite project to Vercel or Netlify.

## Personalise before publishing

In `src/App.jsx`, replace these placeholders with your real details:

- `your.email@example.com` with your professional email address.
- LinkedIn and GitHub profile URLs with your profile URLs.
- Add a real resume PDF to `public/` and add a download link if you want a resume button.
- Add project repository/demo links and verify all project descriptions.
- Update the education and journey section with exact dates and experience details.

The site intentionally does not invent employment dates, employer names, contact details, or project URLs.
